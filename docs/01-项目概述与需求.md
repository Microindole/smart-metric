# 01 项目概述与需求

## 1. 项目背景

- 课程名称：软件质量保证
- 项目名称：SmartMetric 自动化软件度量工具
- 项目目标：构建一个覆盖设计阶段与编码阶段的软件度量工具

## 2. 项目范围

当前实现模块：

- 用例点度量
- 代码行度量
- 功能点度量
- 控制流图与圈复杂度度量
- 面向对象 CK/LK 度量
- 类图级 OO 度量
- 工作量 / 成本 / 工期 / 人员估算
- Web 端与 CLI 端

## 3. 功能需求

建议采用用例图或数据流图描述，至少覆盖：

- 上传设计图并进行分析
- 上传源码并进行度量
- 手工输入功能点/估算参数
- 展示度量结果
- 导出结果
- 通过 CLI 运行度量与自动化测试

## 4. 数据需求

建议采用 ER 图或 UML 类图描述，至少覆盖：

- 用户输入数据模型
- 设计图解析结果模型
- 源码分析结果模型
- 导出结果模型

## 5. 非功能需求

建议从以下角度填写：

- 易用性
- 可扩展性
- 可维护性
- 度量结果可解释性
- 响应时间
- 可测试性

## 6. 输入项与输出项

### 输入项

- 类图 `.xml/.oom`
- 程序流程图 `.json/.mmd/.dot/.xml/.oom`
- 用例图 `.oom`
- 源码 `.java/.c/.cpp/.py/.js`
- 用户手工输入

### 输出项

- 各类度量结果
- 圈复杂度与控制流图
- CK/LK 指标
- 估算结果
- CSV 导出结果
