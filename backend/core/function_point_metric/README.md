# 功能点度量设计说明

本模块用于完成实验指导书中的“功能点度量”。

## 功能点是否需要 AST

功能点度量通常不依赖源码 AST。

它度量的是用户可感知的软件功能规模，输入主要是：

- EI：外部输入。
- EO：外部输出。
- EQ：外部查询。
- ILF：内部逻辑文件。
- EIF：外部接口文件。
- 14 个通用系统特征因子。

因此功能点度量更接近需求/设计阶段度量，而不是源码结构度量。

## 当前公式

```text
UFP = Σ(功能数量 × 权重)
VAF = 0.65 + 0.01 × GSC总分
FP = UFP × VAF
```

权重采用常见 IFPUG 课堂模型：

```text
EI   3 / 4 / 6
EO   4 / 5 / 7
EQ   3 / 4 / 6
ILF  7 / 10 / 15
EIF  5 / 7 / 10
```

## 与 AST 的关系

AST 适合用于：

- 代码行度量。
- 控制流图度量。
- 圈复杂度。
- 面向对象度量。

功能点度量不建议强行用 AST 实现。如果后续要从代码或 UML 自动推断功能点，可以新增解析策略，但最终仍然应该转化为 EI/EO/EQ/ILF/EIF 这些功能点输入项。
