# 05 分析与改进

## 1. 准确性分析

建议对比：

- 手工计算结果
- 工具计算结果
- 差异来源

## 2. 实用性分析

建议分析：

- Web 端适合课程展示与交互
- CLI 端适合批量分析与自动化测试
- 多语言源码分析的实际价值

## 3. 有效性分析

建议结合：

- 设计阶段输入
- 编码阶段输入
- 度量结果对评估和改进的帮助

## 4. 当前局限

建议如实写：

- Java OO 还不是 Eclipse ASTParser 级实现
- C/C++ / JavaScript 的源码级 OO 度量是轻量结构分析
- 控制流图图片识别未实现
- PDF 报告导出未实现

## 5. 后续改进方向

建议写：

- 增强 UML 设计图解析
- 加强 Java AST 语义分析
- 增加结果历史记录
- 增加 PDF 报告导出
