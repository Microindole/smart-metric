# SmartMetric 功能清单

本文件汇总当前仓库已经实现的主要功能，用于替代根目录 `README.md` 中冗长的功能列表。

## 当前已实现

- 用例点度量 `UUC / UAW / TCF / EF / UCP`
- 代码行度量 `LoC`
- 功能点度量 `FP`
- 控制流图导入与圈复杂度度量
  - 支持 `JSON / Mermaid / DOT / OOM / XML`
- 源码控制流分析
  - 支持 `Java / Python / C / C++`
- 面向对象度量 `CK / LK`
  - 源码级支持 `Java / C / C++ / Python / JavaScript`
- 类图级 OO 度量
  - 支持 `.xml / .oom`
- 项目目录级扫描
  - 总代码量
  - 各文件 LoC
  - 依赖关系
  - 设计图清点
  - 上帝文件 / 上帝类排查
- 项目工作量 / 成本 / 工期 / 人员估算
- CSV 导出
- Markdown / HTML / PDF 报告导出
  - 支持从前端已保存的度量结果自动汇总
- 根目录自动化测试脚本
- Web 端与 CLI 端双入口

## 说明

- 项目目录级扫描会自动汇总代码文件和设计图，并复用已有 `LoC / CFG / 用例图 / 类图 / OO` 模块。
- 功能点与项目估算仍属于用户输入驱动模块，不会仅凭目录自动推导。
- `.smartmetricignore` 放在被扫描项目根目录，存在则追加规则，不存在则直接跳过。
- `.smartmetricignore` 当前常用语义尽量对齐 `.gitignore`，支持 `#` 注释、`!` 反向包含、`/` 根路径规则。
