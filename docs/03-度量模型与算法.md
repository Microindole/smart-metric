## 7. AST / 解析策略说明

建议明确写出：

- Java 控制流分析：`javalang`
- Python 控制流分析：标准库 `ast`
- C/C++ / JavaScript / OO 结构分析：策略模式 + 轻量语法分析
- 功能点度量不依赖 AST
